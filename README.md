# Maxlo Throttle

Download the latest version from the [Releases](https://github.com/maxlo-tju/throttle-updates/releases/latest) page.

Maxlo Throttle is a small menu bar app that limits this Mac's internet upload and download so video calls on your network keep working while Maxlo transfers run.

Requires macOS 13 or later. Signed and notarized by Maximum Local Technologies Inc.
